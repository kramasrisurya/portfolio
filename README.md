## ⚡ Overview

A bespoke, editorial-grade portfolio engineered with obsessive attention to craft, performance, and typography. Built with **React 19**, **TypeScript**, **Three.js GLSL shaders**, **Tailwind CSS**, and **Lenis smooth scrolling**, designed after the award-winning design language of high-performance architectural systems.

- **Live URL**: [https://kramasrisurya.github.io/portfolio/](https://kramasrisurya.github.io/portfolio/)
- **ATS Resume**: Included in-app with single-page PDF download and HTML preview.

---

## 🏛️ Architecture & Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite 8](https://vitejs.dev/) with Rolldown compiler
- **3D Graphics**: [Three.js](https://threejs.org/) with custom WebGL GLSL vertex & fragment shaders (2,400-point particle cloud, gyroscopic mouse tilt, additive blending)
- **Smooth Scrolling**: [Lenis](https://lenis.darkroom.engineering/) + [GSAP ScrollTrigger](https://greensock.com/scrolltrigger/)
- **Typography**: `Instrument Serif` (editorial display), `DM Sans` (clean UI body), `JetBrains Mono` (telemetry & code)
- **Styling**: Modern CSS variables with Tailwind CSS utility layer
- **Deployment**: Automated CI/CD via GitHub Actions to GitHub Pages

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/kramasrisurya/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start Vite local development server
npm run dev

# Build for production
npm run build
```
